# Rain recordings

All nine are dedicated to the public domain (CC0 1.0); credit is given as a courtesy.
Each was cut to a clean stretch (no thunderclaps, voices or passing cars that would be
noticed repeating), high-passed and loudness-normalised (the sparse ones to -26 LUFS, the
dense ones to -20 LUFS and played 6 dB down), and stored as 48 kHz Ogg Vorbis. 
`crates/dd-dsp/src/rain.rs` plays them as recorded, moving between random stretches with
slow crossfades so they never audibly loop. The Freesound ones are its public HQ previews
(128 kbps MP3), which carry the same CC0 dedication as the originals.

The sparse ones were chosen by measurement: the gap between the quiet floor and the drops
(95th against 20th percentile of 50 ms levels) is 8–15 dB, against 7–8 dB for a wash.
